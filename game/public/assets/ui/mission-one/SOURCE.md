# Mission 1 typography

Rajdhani Medium is copied unchanged from `assets/ui/focus-kit/v1/fonts/Rajdhani-Medium.ttf`, supplied in the user's Focus kit. Font family by the Indian Type Foundry, distributed under SIL Open Font License 1.1; see the complete `OFL.txt` alongside the font. No font has been installed system-wide or modified.

Used for the scene's dated memory introduction. Layout, live text, fade and corner lines are authored CSS/HTML informed by the supplied Focus kit. No baked sample readouts, mannequin assets, animation sheets or audio are imported. This directory is local runtime data and makes no network requests.
