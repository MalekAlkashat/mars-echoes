# Boulder 01 hub shape

Source: [Poly Haven Boulder 01](https://polyhaven.com/a/boulder_01), Rico Cilliers. [CC0 1.0](https://polyhaven.com/license). Retrieved 14 November 2026.

The hub uses `boulder-01-shape.glb`: 1,200 triangles, 47,916 bytes, SHA256 `3c861ef2be8ac975f1bbbea401e734c42d7695aece3b5585d1792f84d1c9dead`. It shares the existing rock surface with the hub shelves and rubble. Geometry is byte-identical to the decimated textured candidate.

`boulder-01.glb` is the preserved earlier textured candidate (2,879,052 bytes). Original scan, original maps, upstream metadata, decimation and texture-removal scripts are under `assets/vendor/polyhaven/boulder_01`. This is an Earth rock scan adapted for visual use, not measured Martian geology. Only one shelf has received the new shape.
